# 交大课堂转写与 PPT 导出

一个本地 Chrome 扩展，用于在上海交通大学课程播放页导出所选节次的语音转写和 PPT 原始图片。无需 Python 或 npm 安装依赖。

## 安装

1. 在 Chrome 打开 `chrome://extensions`，开启右上角的“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择克隆或解压后的项目文件夹（其中包含 `manifest.json`）。
3. 如果此前已加载本扩展，先在扩展管理页点击“重新加载”，再刷新课程页。
4. 在已登录的 `https://v.sjtu.edu.cn/jy-application-resourcemanage-ui/#/play-center` 课程页面点击扩展图标。导出悬浮窗会出现在页面右上角；可拖动，点击 × 收起，再点扩展图标重新显示。

## 使用

1. 勾选需要的节次。可编辑“按点播页 PPT 文字检索排除”中的词，默认是“签到、点名、考勤”；点击“读取所选节次”。
2. 如果 PPT 图片来自其他域名，点击“授权图片来源”，仅授权显示的图片域名。如果 Chrome 未能在悬浮窗完成提示，可点击“在扩展页授权”；这是权限提示所需的临时页面。
3. 点击“分析图片并预览”。扩展会调用点播页已有的 PPT 文字检索，并检测浏览器、桌面截图。被建议排除的图片默认不保存；可在列表中逐张恢复或手动排除。带课程内容的 PowerPoint 编辑画面不会仅因任务栏而被自动排除。
4. 点击“选择文件夹并导出”，选择本地保存位置。导出期间请保持课程页打开。

每节输出如下：

```text
2026-09-22_第3次课/
├── 2026-09-22_第3次课.txt
├── PPT索引.txt
└── PPT/
    ├── 0001_00-00-01.png
    └── 0002_00-05-43.jpg
```

转写按 `[开始时间 - 结束时间] 正文` 保存。索引列出每张 PPT 的原始换页时间和显示区间；被排除的页面也会保留一行，标明“已排除”与原因，以免把前一张图片误配到该时段。重复导出同一节次时会新建 `(2)`、`(3)` 文件夹，不覆盖之前的数据；已有导出不会被自动修改。

如果文件写入中断，扩展会报告失败；可能留下的文件夹内有 `导出未完成.txt` 标记。图片下载失败发生在建文件夹之前，不会生成误标为完成的结果。

若页面显示“未找到节次数据”或“页面接口已变化”，先刷新课程页并重试。该扩展使用当前播放器的数据结构；学校更新播放器后可能需要同步更新扩展。

## 本地测试

在本文件夹运行 `npm test`。测试只用 Node.js 内置模块，不会访问课程账号或修改浏览器数据。

扩展需在已登录的真实课程页核对一次：勾选一节后，确认转写段数与“语音”栏一致，并核对 PPT 建议排除结果、保留图片的顺序和换页时间。当前开发环境无法直接读取浏览器内的登录会话。
